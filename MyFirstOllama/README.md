# Spring AI
This project demonstrates how to integrate Spring Boot with Spring AI to perform some tasks using a locally hosted Large Language Model (LLM) powered by Ollama.

The application sends both text and image inputs to a multimodal model and receives a natural language explanation of the image.

This project is part of an AI learning journey focused on integrating LLM capabilities into Java enterprise applications.

# Install Ollama

Download from: https://ollama.com

Verify installation:
```
ollama --version
```
